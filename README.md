# 日常打卡

纯本地、免登录的安卓打卡工具，采用 Kotlin、Compose 和 Room。

## 当前状态

开发中，尚非完整交付版本。已实现主要页面、多次起飞记录、补卡统计、JSON/ZIP 备份恢复及提醒基础能力。15 个单元测试通过，调试 APK 构建通过。

本次开发新增（尚未构建验证）：普通/指定日习惯及周/月配额连续统计、习惯列表统计展示、备份历史计划和任务标识校验，以及连续统计与恢复故障测试。

统计规则：指定日习惯按连续完成的应打卡次数计算，休息日不打断；配额习惯按连续达标周/月计算；尚未结束的当日或周期允许继续完成。补卡计入统计，未来记录排除。统计单位发生变化时重置连续及最长统计，累计完成天数保留。

尚待完成：桌面小组件、部分个性化、设备实测、恢复故障测试的设备执行、正式签名和最终审阅。壁纸、音效及震动当前有设置入口，但尚未接入实际展示或打卡反馈。

本次环境验证：本机未安装 Java / Android SDK，Gradle 在启动阶段报 JAVA_HOME 缺失，新增测试尚未执行；上文 15 个测试和 APK 通过为原开发快照的历史结果。

## 构建

需要 JDK 17 或 21、Android SDK 35。配置 ANDROID_HOME 或 local.properties 后执行：

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

Windows 使用 gradlew.bat。build-local.ps1 是原开发环境辅助脚本，其他电脑请使用 Gradle Wrapper。

不含用户数据、SDK、缓存、签名密钥及本机配置。
